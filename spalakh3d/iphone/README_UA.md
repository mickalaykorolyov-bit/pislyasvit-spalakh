# ПІСЛЯСВІТ — iPhone Touch Edition v0.9.52

**Окрема нативна редакція GDevelop** на базі десктопної v0.9.51; десктопний проєкт і його гілку не змінено. У GDevelop відкрити `Spalakh_iPhone_LimboTouch_v0952.json`.

Керування у Safari (горизонтальна орієнтація): утримання пальця зліва / справа — рух; свайп вгору — стрибок; другий палець — стрибок під час руху; свайп униз — пригнутися; тап по видимій 3D-моделі пульта — повернути відповідний прожектор, якщо Спалах підійшов до пульта. Екранних стрілок або кнопок немає. Тап-позиції пультів визначаються їхньою проєкцією у поточній 3D-камері; підтримка мультитачу — рідний InputManager GDevelop.

Усі 105 ресурсів і 385 об'єктів, механіки рівня й камера взяті з v0.9.51. Адаптовано мобільну продуктивність: якість частинок зменшено до `GFX_QUALITY=1`, lens blur shader використовує 11 семплів замість 19 на сенсорних пристроях. Збережена клавіатура для тестів. Маркер у HUD — `iPhone v0.9.52`.

**Safari URL поки що не згенерований.** Для публікації відкрий цей проєкт у GDevelop зі свого акаунту та вибери Share / Publish → Web → Generate link. Ця операція відбувається на сервері GDevelop після входу; наявність файлу на GitHub не означає публікацію HTML5-сайту. Автоматизовані тести логіки дотиків пройдено, реальний Safari/iPhone Preview ще не перевірявся.
