# v0.9.33 — магічний шлейф і об'ємний задній план

Джерело — v0.9.32 CleanUnderwaterDepth, нативний GDevelop 5.

## Полум'я
- Прибрано примусовий великий вигин (старий sin(pi*t)*130).
- Стрічка слідує за історією руху Спалаха, м'яко вигинається й звужується, починається всередині тіла.
- 3 шари з процедурним shader feather: кораловий glow / золотисте полум'я / яскраве майже біле ядро.
- Додані дрібні світлові іскри (процедурні Three.js Points).
- Ширина, довжина й життя шлейфу залежать від швидкості; на зупинці поступово згасають.
- У разі відсутності Three.js залишається нативний спрощений багатошаровий шлейф.

## Задник
- Прибрано інстанси ParallaxRuinsPNG та ParallaxShipPNG. Інші накладки прибрані в v0.9.32.
- Нові **справжні 3D GLB руїни** на 3 глибинах Y: дальні арки/колони (−1385/−1335), середні (−1030/−980), близькі існуючі (−690/−635).
- Dark tinted MeshBasicMaterial тільки для фонових GLB. Жодних змін платформам чи прожекторам.
- Один непрозорий процедурний темно-синій фон на Y −1715, без PNG-оверлеїв; запасний GradientBackdrop зберігається, якщо Three.js недоступний.
- Scene fog: 0.000075 на high, було 0.00012; затемнення декоративного ObsDepthMist до 9/255.
- Сцена повертає верхній navy-ton і глибину без підсвічування дальніх об'єктів.

**Не змінено:** рух і колізії, управління, пазли/рефрактори, камеру, очі павуків, анімації, ресурси, окрему вебверсію.

**Перевірка:** формат native JSON та синтаксис JavaScript перевірено; для візуальної перевірки потрібен GDevelop Preview.
