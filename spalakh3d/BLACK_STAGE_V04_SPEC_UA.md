## 3. Перша навчальна кімната

Порядок подій:
1. **Буй:** A/D рух, SPACE стрибок, E активувати червоний буй → зелена контрольна точка.
2. **Ящик / плита:** фізично підштовхнути вантаж на плиту. При активації змінюється її колір.
3. **Сенсор:** утримувати F та рухатися A/D поблизу сенсора, заряджати шлейфом.
4. **Шлюз:** відкрити вихід і пройти повз рибу; в освітлених ділянках герой невидимий для риби.

Гра показує одну поточну мету у `TutorialTitle`, `TutorialHelp`, `ActionPrompt`. Маркер наступної мети активний лише один. Черговість навчання, керування і фізику ящика у 0.4 не змінювали. 

## 4. Спалах у 3D

**Поточний технічний файл:** `spalakh3d/assets/spalakh_flame_v04.glb`; змінено Model3DObject Player, збережено існуючий фізичний контролер.
- Новий суцільний mesh об'ємного персонажа: велика округла жовто-золота голова, видовжені назад полум'яні пасма, маленький корпус, дві руки та дві ноги, чорні овальні очі.
- Жовтий світний центр, помаранчева основа, червоно-рожеві кінчики та спалахи, 7 матеріалів із `emissiveFactor`.
- Видалено окремі блокові `HeroBody`, `HeroFlame` і `HeroEye` з ігрових інстансів — новий персонаж тепер єдина модель.
- Навколо героя тепле `EmberLight`, при рухові — невеликі частинки `Spark`.
- Це процедурно змодельована спрощена 3D-інтерпретація референсу, а не повністю скульптована/текстурована модель і не з анімацією волосся. Анімації idle, run, jump, fall — завдання наступної ітерації.

## 5. Критерії тестування у GDevelop Preview
- [ ] Нема білих ділянок фону чи фотографічних текстур на кубах.
- [ ] Платформи темні, але краєві лінії розпізнаються; прірва темніша.
- [ ] Нова GLB-модель Спалаха завантажується, має правильну орієнтацію й масштаб у кадрі.
- [ ] Буй red/green, плита, заряд сенсора й шлюз працюють як раніше.
- [ ] У світлі риба не бачить Спалаха, у темряві реагує на нього.
- [ ] Відкриття через `?project=` працює без архіву, Preview запускається без JavaScript errors.
- [ ] Перевірити фізику й зіткнення; імітаційні JS тести не замінюють запуск у реальному браузері.

## 6. Статус і наступні кроки
Версія `0.4.0` завантажена у GitHub. GLB має 29 mesh-примітивів, 7 матеріалів, перевірений як коректний GLB 2.0 JSON + BIN. JavaScript пройшов 224 імітаційні кроки, включно з буєм, сенсором, шлюзом, перезапуском. Реальний рендер Preview ще не перевірено — результат і масштаб потрібно оцінити на скриншоті гравця.

**Наступна версія:** v0.5 — коректна орієнтація моделі (якщо необхідно), анімації вогняного волосся, ходіння, стрибок, кінематографічне посилення шлейфа.
