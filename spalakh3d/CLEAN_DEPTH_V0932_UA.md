# v0.9.32 — виправлення заднього плану паралаксу

База: v0.9.31 WideFireRibbon. Виключно нативний GDevelop 5 / 3D scene Observatory3D_FalseLight.

## Причина

Попередній v0.9.30 одночасно накладав чотири великих PNG, CanvasTexture blur і сильний синьо-блакитний FogExp2. Велике декоративне обрамлення візуально перекривало ігровий майданчик і зменшувало контраст.

## Правки

- Повністю прибрано старе runtime CanvasTexture-розмиття.
- Із **інстансів сцени** прибрано ParallaxSkyWaterPNG та ParallaxForegroundFramePNG (їхні object definitions та ресурси не видалено).
- ParallaxRuinsPNG: розмір 5000×1350, координати (-1300,-1450,-880), непрозорість 31%, темно-синій тон.
- ParallaxShipPNG: 2100×890, координати (400,-1190,-720), непрозорість 41%, синьо-сірий тон.
- GradientBackdrop збережено, невелике приглушення кольору, без дублювання іншого неба.
- 3D FogExp2 щільність зменшено з 0.00034 до 0.00012, колір — темний океанський 0x0a1a31; фон сцени 5;13;29.
- Дві декоративні площини ObsDepthMist приглушено до 27/255 (~11%). Пазлові прожектори та їхня логіка не змінені.

Глибина лишається фізичною через Y-координати 3D GDevelop. Задник залишається читабельним як тихі силуети під ігровим планом, без передніх прозорих плям.

Проверено структуру JSON і синтаксис JS, **реальний Preview GDevelop потребує перевірки**. Вебверсію не створювали й не редагували.
