# v0.9.31 — яскравий широкий шлейф Спалаха

Джерело: v0.9.30 SoftDepthParallax, тільки нативний GDevelop JSON.
Замість окремих помаранчевих прямокутників шлейф рендериться безперервною трисмуговою геометрією (Three.js MeshBasicMaterial):
- рожево-кораловий широкий зовнішній шар,
- янтарно-жовтий середній шар,
- гаряча майже біла внутрішня смуга.

Геометрія будується за історією координат героя, плавно вигинається вгору й звужується до кінчика. Шлейф зростає на високій швидкості, гасне на зупинці. Повернення в інший бік очищує стару історію, щоб шлейф не перетинав персонажа. Шлейф розміщений позаду площини персонажа. Три шари без колізії, без впливу на геймплей.

У старих версіях GDevelop, якщо Three.js-доступ до сцени недоступний, залишається широкий спрощений шлейф зі старих 22/22/18 3D білбордів.

НЕ змінено фізику, взаємодію з рефракторами, шари паралаксу, камеру, анімаційні кадри, світло, інтерфейс чи незалежну вебверсію.

Перевірено JSON та синтаксис JS. Результат GDevelop Preview потрібно перевірити в редакторі.
