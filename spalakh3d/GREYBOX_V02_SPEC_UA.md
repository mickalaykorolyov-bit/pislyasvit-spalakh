# ПІСЛЯСВІТ 3D — Visual direction 0.2

## Мета
Minimal 3D cinematic blockout / INSIDE-like greybox with colored light accents. Передача настрою через світло та масштаб, а не детальні текстури. Геймплей прототипу (GDevelop Starting 3D Platformer physics, Спалах, буй, плита, сенсор, шлюз, риба) зберігається.

Ці величини — початкові для greybox, їх потрібно оцінити безпосередньо в GDevelop Preview і за потреби скоригувати на реальному GPU.

## Сцена
- Залишити дві прохідні секції з невеликим проваллям; вхід — Спалах, далі буй, вантаж, плита, сенсор, риба і шлюз.
- Додати монументальні, але непомітні далекі конструкції: FarMass, FarPillar, FarBeam, Substructure.
- Далекі форми мають бути темнішими за ігрові платформи. Прірва має читатися як порожній темний простір.
- Туман поки що імітується кольоровою перспективою й освітленням (без спеціального об'ємного fog shader).
- Не змінювати колізії та фізику з базового шаблону без окремого тестування.

## HUD
- Зменшити заголовок до 17 px, завдання 19 px, статус 14 px, підказку керування 13 px.
- Теплий колір залишити на Спалахові та подієвих індикаторах; увесь текст — холодний світло-сірий/бірюзовий.
- Розміщення: завдання зверху, статус та керування знизу.

## Acceptance criteria
1. Немає декоративних текстур каміння, металу, водоростей або дерева.
2. Задній фон #0B171F, без білих порожнин.
3. Платформи, провалля, буй і сенсор чітко читаються без підписів.
4. Буй перемикається з червоного на зелений; шлейф заряджає сенсор за попередніми правилами.
5. Під час запуску не виникають JavaScript Runtime errors.
6. Перевірити в GDevelop Preview масштаб персонажа, camera angle, fps, реакцію риби й 3D-фізику.
