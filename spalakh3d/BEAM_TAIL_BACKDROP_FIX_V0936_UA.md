## 1. Промені
- Причина зсуву: джерело `getX()+getWidth()*.5, getZ()+getDepth()*.48` — не лінза. У GLB лінза (матеріал `lens`) ≈ (0.50, 0.80, 0.51) бокса моделі, а `originLocation: ModelOrigin` означає, що бокс не починається в X/Z об'єкта (різниця ≈ 45 по X і ≈ 35 по Z для даного масштабу).
- Тепер центр лінзи **вимірюється** з меша лінзи кожного прожектора (Box3 по матеріалу `lens`) і кешується; якщо виміряти не вдалося — розрахунок за розкладкою GLB.
- Промінь — один перевикористовуваний Three.js меш на промінь (6 вершин, без аллокацій у кадрі): вузький біля лінзи (±9) → ширший до поверхні (до ±135), м'які боки, плавне проявлення біля лінзи, плавне згасання перед поверхнею; над провалом промінь розчиняється раніше. Жорсткого обрізаного краю немає.
- Насиченість `[0.80, 0.55, 0.90]` від базової (на 20 / 45 / 10 % менше), без підвищення експозиції.
- Пляма-контакт `ObsSpotlightFootprint`: м'яка еліптична, розтягується при похилому падінні, лежить на верхній площині деки, прозорість узгоджена з променем; при провалі — прихована. `ObsSpotlightImpactLight` — як було.
- Не змінено: `s.modes`, `travellingRay()`, `projectorImpact()`, рефрактори, bridge/iris, safe-zones.
- Запасний варіант без Three.js: старий нативний `ObsLightCone` з виправленою точкою джерела й `setOpacity`.

## 2. Квадрат навколо Спалаха
- Причина: герой — прозорий спрайт 300×196, що **пише глибину по всьому прямокутнику**, а стрічка хвоста лежить за ним на 6–12 одиниць і малювалась після нього (renderOrder 30+) → усі пікселі хвоста всередині прямокутника відкидались depth-тестом.
- Виправлення без `depthTest:false`: хвіст малюється першим (renderOrder 40–43), спрайти героя (50) та `SpalakhAura` (48) — після. Непрозорі платформи попереду, як і раніше, закривають хвіст. Форма, довжина, швидкісна адаптація шлейфу не змінювались.

## 3. Куполи ObsDome
- Корпуси (`stone/stoneMid/dome/edge/purple`) → sRGB `#0a1626 / #0d1b2d / #0c1a2b / #132438 / #15193a` (unlit, як інші руїни). Вікна (`window/warm`) → приглушений бурштин `#6c4c2c / #7a5733`, фініал (`cyan`) → `#1b5560`. Матеріали створюються для кожного екземпляра окремо; прожектори, платформи та інші GLB не торкаються. Поділ геометрії зберігається. Фіолетове підсвічування руїн v0.9.35 без змін.
