# ПІСЛЯСВІТ 3D — v0.6 / NEON RUINS
## Production brief / затверджений артнапрям
Візуальний принцип: **no illustrative/photo textures — only form, gradients, light and neon**. Технічний PNG 64×128 містить лише згенерований синьо-бірюзовий колірний градієнт для дальнього фону. Усі куби, арки та корали використовують суцільний колір + технічний білий матеріал 2×2 для tint; це не камінь, дерево чи намальована фактура.

### 2. Геометрія
- **ArchDark** / **ArchMid** / **ArchHighlight** / **ArchSeam**: модульні 3D-куби, що формують три великих відкритих аркових портали + дальній четвертий, вид збоку, з піднятим карнизом і ступінчастими заокругленими кутами.
- Масштаб орієнтовного порталу: ширина 440×scale, висота 430×scale, колони 78×scale. Глибина 100×scale. Складальна низькополігональна модульна архітектура; необов'язкова bevel-модель — наступний крок.
- **TopHighlight**, **StepEdge**: тонкі однотонні світлові канти й сегментовані лінії на дальньому боці платформ. Вони не мають колізій.
- Видалені тільки старі інстанси фонових Ruins/Rocks/Rail/FarMass/FarPillar/FarBeam/Substructure. Основна підлога, підвищення, фізичний ящик, буй, сенсор, шлюз не змінені.

### 3. Неонові рослини (створені три основні + додаткова)
- **NeonCoralCyan**: бірюзові багатогілкові «водорості», RGB 93;246;235.
- **NeonCoralPink**: рожеві м'які розгалуження, RGB 255;130;214.
- **NeonCoralBlue**: блакитні коралові гілки, RGB 132;175;255.
- **NeonCoralLavender**: фіолетові гілки для глибини, RGB 186;133;235.
- Кожен кущ складається з 6 простих 3D-боксів різної висоти/нахилу, Basic unlit, без фототекстур і фізичних зіткнень.
- **Важливо для геймдизайну:** корали — декоративні неонові об'єкти. Вони самі НЕ створюють безпечних стелс-зон. Невидимість від риби залишається прив'язана до прожекторів / спеціально позначених safe light sources, щоб не обманювати гравця.

### 5. Перша кімната
1. Старт: Спалах стоїть на чорному блоці під великим порталом. Ліворуч неон, праворуч вузьке провалля.
2. Гравець рухається праворуч через кам'яні модулі, активує червоний буй (E); стан червоний→зелений.
3. Переміщує фізичний ящик на плиту; натискна платформа зелено-бірюзово підсвічується.
4. Заряджає сенсор шлейфом (F у русі), відкриває шлюз і уникає риби в освітлених зонах.
5. HUD — одна ціль та мінімальні підказки; жодних нових пояснень для декору.

### 6. GDevelop production pipeline
- Scene: GDevelop 5, official `starting-3D-platformer` movement/physics; 3D BoxObjects використовуємо як модулі; `Player` фізичний та прихований.
- Hero: 12 анімованих прозорих PNG-площин idle/run/jump/fall; одна активна одночасно, слідує за фізичним Player; світло EmberLight.
- Assets: `flat_white.png` (нейтральна заливка) + `underwater_gradient_v06.png` (чистий градієнт) + PNG Спалаха + існуюча GLB риба. Корали, руїни, платформи **не мають ілюстративних текстур**.
- Modular scale → instance-based architecture → cold/warm lighting pass → check camera + physics → optimize draw calls.
- Тестування: відкриття editor.gdevelop.io через GitHub raw `?project=`, Preview, оцінка кадру, колізій, маркерів, FPS, геймплею; потім v0.7 з об'ємними заокругленими моделями та більш плавними неоновими стеблами.
