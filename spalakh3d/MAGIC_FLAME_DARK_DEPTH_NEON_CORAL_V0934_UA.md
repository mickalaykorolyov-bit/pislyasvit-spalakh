# v0.9.34 — Magic Flame · Dark Depth · Neon Coral

Основа: v0.9.33 (`spalakh-25d-magic-depth-v0933`). Нативний GDevelop 5, без вебверсії.

## 1. Шлейф
- Причина білої плями: два шари `AdditiveBlending` (alpha .78/.92, колір до 1,1,.77) на широкій стрічці, що складається сама на себе під час стрибків/розворотів → накопичення до чистого білого.
- Тепер усі три шари — premultiplied **NormalBlending**, жорсткий cap alpha ≤ .72, колір ≤ (1, .97, .88); `depthWrite` у межах шару з кроком глибини на семпл — перекриття не накопичуються.
- Ширина ≤ 0.92 висоти тіла (150), довжина 0.9–3.0 висоти тіла залежно від швидкості, без вигнутої «арки». Градієнт: кремовий → золотий → помаранчевий → корал, м'які нерівні краї, локальне світле ядро.
- Іскор 14 (additive, значення ≤ .55). Ресурси перебудовуються лише при зміні Three-сцени, старі dispose.

## 2. Задник
- Причина світло-сірих руїн: кольори передавались у `Color.setRGB(0.105,…)` — це лінійні значення, на екрані ≈ (92,128,161). Тепер sRGB-hex: far `#08121e`, mid `#0c1a2b`, near `#112338`, alpha .90–.94.
- Градієнтний фон піднято до z=5200 (верх — глибокий синій), додатково `scene.background`; fog 0.00005 того ж кольору, що й дальні руїни.
- Фіолетове світіння: щоразу максимум 2 арки (далекі/середні), цикл 8 с, плавне зростання/спад.

## 3. Корали
- Модель: власна копія матеріалів/геометрії, кольоровий градієнт + emissive у кольорі корала з індивідуальним «диханням» (7–11 с).
- Палітра: cyan / pink / violet / **yellow** / **white**; розподіл по 9 коралах (`PLAN` у JS).
- Реальні `PointLight3D` (по одному на корал, intensity 3.1, decay 1, range 340) + плоский ореол + м'яка пляма-відблиск на верху платформи (`ObsCoralSpill*`). Кількість світел стала, лише змінюється intensity.

Не змінено: фізика, колізії, камера, керування, анімації, пазли, павуки, HUD.
